配置流程与操作说明

AiBox 将配置流程拆成清晰步骤，即使首次使用机场订阅也能较快完成连接。

第一步：选择套餐并获取订阅链接

根据流量与设备数量选择基础版、旗舰版或团队版。订阅完成后，在官方账户中复制专属订阅地址（Clash 或通用格式）。请妥善保存该链接，后续换设备只需重新导入。

第二步：安装对应客户端

Windows 与 macOS 可使用图形化 Clash 客户端；Android 使用 Clash Meta 类应用；iOS 使用 Shadowrocket、Stash 等。安装后打开软件，确认已授予网络与 VPN 相关权限。

第三步：导入并更新配置

在客户端的订阅或配置页面粘贴 AiBox 链接，执行更新。成功后将出现节点列表。部分客户端支持扫描二维码，可减少手动输入错误。

第四步：测速、选节点并连接

优先选择延迟较低的香港、日本或新加坡节点作为日常线路，美国节点用于特定流媒体。开启规则或全局模式后点击连接，状态显示已连通即可开始加速。游戏场景建议切换 IPLC 优化节点。

第五步：日常维护

定期点击更新订阅以同步新节点。若某一线路变慢，直接切换即可。旗舰版用户可走优先工单通道反馈日志。合理分流（国内直连、国外代理）能进一步提升速度并节省流量。

常见问题

AiBox 是什么？和普通 VPN 有何不同？

AiBox 是官方运营的机场订阅与网络加速服务。用户获得的是可导入各类客户端的节点订阅，而非单一封闭 App。这样可以自由选择 Windows、Mac、手机或路由器方案，并按套餐使用不同质量的线路与解锁能力。

怎样完成从购买到第一次连接？

先选定基础版、旗舰版或团队版并完成订阅，复制链接；再按本页「配置流程」安装客户端、导入更新、选择低延迟节点后连接。多数用户可在数分钟内完成。详细分步见上方操作说明。

各套餐流量和设备数量如何计算？

基础版每月 100GB、同时 3 台；旗舰版 300GB、5 台；团队版 1000GB、20 台。仅统计走代理的国际流量，国内直连一般不计入。同时在线数以实际建立的连接为准，更换设备重新导入订阅即可。

节点分布和速度表现怎样？

主要提供香港、日本、韩国、新加坡、台湾、美国及部分欧洲节点。普通线路满足浏览与基础解锁，旗舰版和团队版可使用 IPLC 专线与原生流媒体 IP，游戏与晚高峰体验更稳定。具体延迟因本地网络而异，建议在客户端内测速后选择。

连接失败或速度慢时如何处理？

先更新订阅并更换节点，检查系统时间、客户端版本以及是否开启正确代理模式。可尝试切换网络或重启软件。仍无法解决时，旗舰版及以上可通过优先工单提交日志。多数问题出在本地设置，对照配置流程逐步排查即可。
